    51→## API CONTRACTS (agreed for agents 3-a / 3-b)
    52→
    53→### 3-a: Core APIs
    54→- POST /api/auth/login {userId, pin} → PUser (validates pin, active)
    55→- GET /api/users → list (no pin). POST /api/users {name,pin,roles,color}. PATCH /api/users {id, ...fields, active}
    56→- GET /api/products?q=&category=&low=&supplierId= → {products, categories}. POST /api/products {name,barcode,buyPrice,sellPrice,...}. PATCH /api/products {id,...}. 
    57→- POST /api/products/parse (multipart file) → {rows:[{name,barcode,buyPrice,sellPrice,stock,category,duplicateOfId?,status:'new'|'duplicate'|'merge'}], total} (xlsx parse, header mapping fuzzy)
    58→- POST /api/products/commit {rows:[...]} → imports with merge/skip/create strategies
    59→- POST /api/products/image-search {query} → {images:[url...] } (uses z-ai-web-dev-sdk backend image search; fallback empty + error field)
    60→- PATCH /api/products/image {id, imageUrl} 
    61→- GET /api/suppliers → {suppliers with companies+productCount}. POST /api/suppliers {name,kind,companyIds,paymentTerms,chequeDays,phone}. PATCH /api/suppliers
    62→- GET /api/companies → {companies with supplier names + products w/ stock}
    63→- GET /api/orders?status=&supplierId=&active= → {orders incl supplier, item count, total}
    64→- POST /api/orders {supplierId, receivingDate, paymentType, note, items:[{productId,name,barcode,qty,unitCost,sellPrice}]} → creates DRAFT|SUBMITTED (sendStatus), event, notifications, audit
    65→- GET /api/orders/[id] → full order (items, events, supplier, cheques)
    66→- PATCH /api/orders/[id] {action:'update'|'submit'|'approve'|'reject'|'cancel'|'correct'|'receive'|'confirm'|'done'|'updatePayment', userId, ...} → lifecycle transitions:
    67→  - update: edit items (only DRAFT/SUBMITTED), recalc totals
    68→  - submit → SUBMITTED (notify GM), approve → APPROVED (notify inv+delivery), correct → append correction + event
    69→  - receive: {items:[{id,deliveredQty,printedPrice,status,note,finalCost}], userId} → status RECEIVED, deliveredAt, recalc from delivered, notify inventory+accountant, audit
    70→  - confirm: same shape → CONFIRMED (recalc confirmedQty), notify accountant
    71→  - done: → DONE, notify GM/PM/owner
    72→  - Each transition: OrderEvent + AuditLog + notifications
    73→- GET /api/export/order/[id] → xlsx file (SheetJS): columns barcode/name FA name/qty/unit cost/printed price/discount/tax/vat/total; header block w/ order code, supplier, totals
    74→- GET /api/dashboard → counts (orders by status, low stock, cheques pending, tasks open), charts (orders/day last 14d, spend/day, top suppliers), recent events, staff points leaderboard
